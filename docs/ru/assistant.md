# Ассистент

Ассистент это чат с языковой моделью, которая знает ваш дом. Он отвечает на вопросы о состоянии дома и о работе Valo, собирает панели, заводит помещения и предлагает действия. Ассистент работает только через те же права, что и вы, и не делает ничего сверх них.

## Что умеет ассистент

Чтение, выполняется сразу

- обзор дома, список устройств, состояние и история показаний устройства
- помещения, панели, каталог виджетов, сцены, сценарии и блоки сценариев, расширения
- последние события журнала
- поиск и чтение этой документации и описаний расширений
- для администратора сведения о сети Zigbee и чтение исходного кода ядра без права изменения

Изменения, выполняются сразу и отменяются кнопкой **Отменить**

- создание панели, изменение панели и добавление виджетов на панель
- для администратора создание и изменение помещения, раскладка устройств по помещениям и переименование устройства

Действия с подтверждением, выполняются только после кнопки **Выполнить**

- команда устройству, например включить свет или задать уставку
- применение сцены, удаление панели
- создание, изменение, удаление и ручной запуск сценария
- для администратора удаление помещения, установка расширения из каталога и открытие сети Zigbee для сопряжения

## Как пользоваться

1. Откройте **Ассистент** в меню
2. Напишите вопрос или задачу в поле **Сообщение ассистенту** и нажмите **Отправить** или Enter. Shift и Enter переносят строку
3. В пустом чате есть готовые примеры, например **Что сейчас происходит дома?** или **Сделай панель с графиком напряжения розетки**
4. Пока ассистент работает, видно, что он думает и какие данные запрашивает, например Обзор дома или Устройства. Кнопка **Остановить** прерывает ответ

## Карточки действий

Каждое изменение и каждое действие с подтверждением показывается карточкой с кратким описанием и статусом.

- **ждет подтверждения** с кнопками **Отклонить** и **Выполнить**
- **выполнено**, у отменяемых действий есть кнопка **Отменить**, у созданных панелей и устройств ссылка **Открыть**
- **отклонено**, **отменено** или **ошибка** с причиной

Отмена возвращает прежнее состояние, например удаляет созданную панель или возвращает старое имя устройства. Команды устройствам, сцены и сценарии отменить нельзя, поэтому они требуют подтверждения заранее.

## Права

Ассистент получает роль и ограничения пользователя, который пишет в чат.

- гость может только спрашивать, ассистент ничего не меняет за него
- жилец может просить панели, команды устройствам, сцены и ручной запуск сценариев
- администратор дополнительно может просить помещения, раскладку устройств, переименование, создание и изменение сценариев, установку расширений и сопряжение
- пользователь с доступом только к части помещений видит через ассистента только эти помещения, работа со сценариями ему недоступна

Токен API с правом только чтения писать в чат не может. Администратор может задать лимит сообщений в день на одного пользователя.

## Список чатов

Слева находится список ваших чатов, у каждого пользователя он свой. Кнопка **Новый чат** открывает пустой чат, название ставится по первому сообщению. У каждого чата есть кнопки **Переименовать** и **Удалить**, удаление нужно нажать дважды. Чат, где ассистент еще отвечает, помечен словом **отвечает**.

## Настройка

Ассистенту нужен ключ API провайдера моделей. Администратор задает его в разделе Система, вкладка **ИИ**.

- **Ассистент включен** включает и выключает ассистента для всех
- **Адрес API** указывает OpenRouter или совместимый API
- **Модель** выбирается из списка после кнопки **Загрузить список моделей**
- **Ключ API** хранится зашифрованно и не показывается после сохранения
- **Температура**, **Шагов на ответ** и **Лимит сообщений в день** уточняют поведение
- **Проверить** отправляет модели пробный запрос

Пока ключ и модель не заданы, в чате показано **Ассистент не настроен** и ссылка **Настроить** для администратора. В демо среде ассистент работает на демонстрационной модели без ключа. Подробнее о вкладке ИИ в [Система](/docs/system).
