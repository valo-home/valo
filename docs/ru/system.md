# Система

Раздел **Система** собирает настройки дома, пользователей, токены API, резервные копии, журнал ошибок, настройки ассистента и состояние узла. Набор вкладок зависит от роли. Администратор и владелец видят все вкладки, жилец и гость только **Токены API** и **Состояние узла**.

## Дом

- **Название дома**
- **Широта** и **Долгота**. По ним считаются восход и закат для сценариев, по ним же берут погоду расширения
- **Часовой пояс**. В нем работают расписания сценариев и считается расход за сегодня
- **Валюта** для стоимости энергии
- **Язык** дома. На нем формируются тексты уведомлений, в том числе внешних, и имена новых устройств расширений
- **Сколько дней хранить подробную историю**. Более старые значения устройств удаляются
- **Уровни уведомлений для внешней доставки**. Уведомления этих уровней уходят во внешние каналы, например в Telegram. По умолчанию только критично. Блок **Уведомление** с отметкой **Отправить наружу** уходит независимо от этой настройки
- **Ежедневная резервная копия**. Включает автоматическую копию раз в сутки ночью. Если ночью узел был выключен и копии нет больше 26 часов, она создается в течение часа после включения

Нажмите **Сохранить**, чтобы применить изменения.

## Пользователи

Таблица пользователей с именем, логином, ролью, доступными помещениями и временем последнего входа.

1. Нажмите **Добавить пользователя**
2. Заполните **Имя**, логин, **Пароль** не короче шести символов, **Роль** и **Язык**
3. В **Доступ к помещениям** отметьте помещения, если пользователь должен видеть только их. Если помещения не выбраны, ограничения нет
4. **Сохранить**

Нажатие на имя открывает пользователя для изменения. Пустое поле пароля оставляет прежний пароль. Снимите **Учетная запись активна**, чтобы временно запретить вход, или удалите пользователя кнопкой **Удалить** с подтверждением. Себя удалить нельзя. Последнего владельца нельзя понизить, отключить или удалить.

## Роли

- **Гость** только смотрит дом, панели, устройства, сценарии, журнал и страницы расширений
- **Жилец** дополнительно управляет устройствами, применяет сцены, запускает и проверяет сценарии, создает и меняет панели, создает свои токены API
- **Администратор** дополнительно настраивает помещения и устройства, подключает устройства Zigbee и MQTT, создает сценарии и сцены, ставит и настраивает расширения, управляет пользователями кроме владельцев, меняет настройки дома, создает резервные копии, видит ошибки и настраивает ассистента
- **Владелец** может все, в том числе восстанавливать узел из копии, загружать копии, менять канал Zigbee и назначать других владельцев

Ограничение по помещениям действует для любой роли. Пользователь с ограничением видит и меняет только устройства своих помещений.

Ассистент действует с правами того, кто с ним говорит, подробнее в [Ассистент](/docs/assistant).

## Токены API

Токен дает внешней программе доступ к API Valo от вашего имени.

1. В блоке **Новый токен** введите **Название**
2. Выберите **Права**. **чтение** только смотрит, **управление** еще и управляет устройствами, сценами и сценариями на уровне жильца
3. Задайте **Срок действия, дней**, 0 или пустое поле означает бессрочно
4. При необходимости ограничьте токен помещениями
5. Нажмите **Создать** и сразу скопируйте токен кнопкой **Копировать**. Он показан один раз

Программа передает токен в заголовке `Authorization: Bearer <токен>`, адрес API `/api/v1`, например `http://<адрес узла>:3100/api/v1/devices`. Токен никогда не дает больше прав, чем у вашей роли. В таблице видно, когда токен использовался в последний раз и до какого числа действует. Ненужный токен удалите кнопкой **Удалить**. Администратор видит токены всех пользователей, остальные только свои. Создавать токены может жилец и выше.

## Резервные копии

Копия содержит базу дома (устройства, помещения, панели, сценарии, сцены, настройки), список и настройки расширений и данные Zigbee2MQTT.

- **Создать копию** запускает копирование сразу. Ежедневная копия создается автоматически, если она включена во вкладке Дом
- В таблице видны время, вид копии (вручную, по расписанию, загружена), состояние и размер
- **Скачать** сохраняет файл `.tar.gz`. Храните копию вне дома
- **Удалить** удаляет копию, нажатие нужно подтвердить
- Пометка «копия на второй диск не записана» значит, что дубликат копии на втором диске узла не создан

Восстановление доступно только владельцу.
1. Если копии нет в списке, нажмите **Загрузить копию** и выберите файл. Архив проверяется и появляется в списке с видом загружена
2. У нужной копии нажмите **Восстановить**, затем **Подтвердить восстановление**
3. База заменяется целиком в одной транзакции, затем ядро заново читает сохраненные сообщения брокера

Текущее состояние при восстановлении теряется. Если оно может понадобиться, сначала создайте свежую копию кнопкой **Создать копию**.

Данные Zigbee2MQTT из копии при восстановлении автоматически не возвращаются. Они нужны только при замене узла или стика, этим занимается администратор узла.

## Ошибки

Журнал ошибок ядра, его процессов, Zigbee, расширений, веб сервера и браузеров пользователей. Одинаковые ошибки собираются в одну запись со счетчиком, временем первого и последнего появления. Раскройте запись, чтобы увидеть источник, подробности и трассировку. Новые ошибки выделены, их число показывает строка **Ошибки** внизу меню. **Обновить** перечитывает список, **Очистить** удаляет все записи после подтверждения. Данные об ошибках не покидают узел.

## ИИ

Настройки ассистента.
- **Ассистент включен**
- **Адрес API** совместимого с OpenAI сервиса, по умолчанию OpenRouter
- **Модель**. Кнопка **Загрузить список моделей** подсказывает названия при вводе
- **Ключ API**. После сохранения ключ хранится зашифрованно и не показывается, **Удалить ключ API** стирает его
- **Температура**, **Шагов на ответ**, **Лимит сообщений в день** на одного пользователя, 0 без лимита

**Сохранить** применяет настройки, **Проверить** отправляет модели пробный запрос и показывает ответ или ошибку. Как пользоваться ассистентом, описано в [Ассистент](/docs/assistant).

## Состояние узла

- **Версии** ядра, веб клиента, Python, Mosquitto и Zigbee2MQTT
- **Службы** с состоянием базы, Redis, процессов MQTT и WebSocket, фоновых задач, супервизора расширений и Zigbee2MQTT. Красная точка означает, что служба не отвечает
- **Ресурсы** для администратора. Загрузка процессора, память, диск, размер базы и время работы
- **Обновление ядра** для администратора. Установленная версия и наличие новой
