## Що робить

Стежить за прогрівом сауни за датчиком температури, показує віджет із прогресом, дає тригер «Сауна готова».

## Разове налаштування

1. Встановіть розширення
2. Оберіть **Пристрій** із температурою сауни та **Готовність** (наприклад 70)

## Як користуватися

Додайте віджет на панель. Тригер **Сауна готова** разом із повідомленням у Telegram повідомить, що можна йти.
