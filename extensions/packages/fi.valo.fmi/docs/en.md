## What it does

Fetches the Finnish Meteorological Institute forecast for the home town and creates a virtual Weather device. Adds the flow conditions "Rain expected" and "Frost expected".

## One-time setup

1. Install the extension
2. Set **Place** (a town, for example Espoo) and source `api`

## How to use

Use the Weather device in conditions and dashboards. **Rain expected** takes a number of hours, **Frost expected** helps with heating automation.
