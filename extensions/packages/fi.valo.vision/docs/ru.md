## Что делает

Распознает на кадрах камер людей, машины, животных, велосипеды, мотоциклы, грузовики и автобусы. Работает на процессоре узла Valo, облако и интернет не нужны. Анализ идет только во время движения от камеры и несколько секунд после, в остальное время расширение не нагружает процессор.

Для каждого найденного объекта появляется событие камеры с меткой, например **Человек**, с оценкой уверенности и рамкой. К первому кадру события сохраняется снимок с нарисованной рамкой. Эти события видны на странице камеры, пишут клип по правилам записи камеры и запускают сценарии с триггером события камеры.

## Разовая настройка

1. Включите в камере определение движения, распознавание начинается по сигналу движения от камеры
2. Установите расширение и подтвердите права **Видео камер для анализа**, **События распознавания на камерах**, **Сохранение снимков и клипов** и **Чтение состояния устройств**
3. Откройте **Камеры**, страницу камеры, затем **Настройки**, раздел распознавания
4. Включите распознавание, выберите метки и порог уверенности, при необходимости нарисуйте зоны и сохраните

## Зоны

Зона это многоугольник на кадре. Точки ставятся кликом или касанием, их можно перетаскивать, двойной клик по точке удаляет ее. Объект относится к зоне по нижней середине рамки, то есть по месту, где он стоит.
- **Учитывать**. Если есть хотя бы одна такая зона, события появляются только для объектов внутри них
- **Игнорировать**. Объекты в этих зонах не учитываются, например улица за забором

## Параметры

- **Кадров в секунду во время движения**. По умолчанию 1, больше дает быстрее реакцию и больше нагрузку
- **Конец события после пропадания**. Сколько секунд объект должен отсутствовать, чтобы событие закончилось, по умолчанию 6
- **Наибольший анализ за одно движение**. Защита от бесконечного движения, по умолчанию 300 секунд

## Модель

Используется YOLOX tiny (лицензия Apache 2.0) через onnxruntime на процессоре. Один кадр дополнительного потока анализируется примерно за 0,1 секунды одним ядром. Файл модели входит в пакет и проверяется по контрольной сумме при запуске. Ускорение на встроенной графике Intel пока не используется, в образе нет среды OpenCL для нее.
