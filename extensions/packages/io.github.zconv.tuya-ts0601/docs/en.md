## What it does

External Zigbee2MQTT converter for a Tuya TS0601 floor heating thermostat variant that Zigbee2MQTT does not recognize on its own.

## One-time setup

1. Install the extension, the converter loads into Zigbee2MQTT without a restart
2. If the thermostat was paired as unsupported, run "Interview again" for it

## How to use

The thermostat appears with temperature and setpoint. Only install converters from a trusted catalog.
