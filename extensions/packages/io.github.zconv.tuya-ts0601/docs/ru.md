## Что делает

Внешний конвертер Zigbee2MQTT для варианта термостата теплого пола Tuya TS0601, который Zigbee2MQTT не распознает сам. После установки устройство определяется с температурой, уставкой и режимом.

## Разовая настройка

1. Установите расширение. Конвертер загружается в Zigbee2MQTT без перезапуска
2. Если термостат уже был подключен как неподдерживаемый, на странице Zigbee выполните для него «Повторный опрос»

## Как пользоваться

Термостат появится как обычное устройство с функциями температуры и уставки. Удаление расширения убирает конвертер из Zigbee2MQTT.

Внешний код в Zigbee2MQTT ослабляет его защиту, ставьте только конвертеры из доверенного каталога.
