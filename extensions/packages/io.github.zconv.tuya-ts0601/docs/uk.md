## Що робить

Зовнішній конвертер Zigbee2MQTT для варіанта термостата теплої підлоги Tuya TS0601, який Zigbee2MQTT не розпізнає сам.

## Разове налаштування

1. Встановіть розширення, конвертер завантажується в Zigbee2MQTT без перезапуску
2. Якщо термостат уже підключений як непідтримуваний, виконайте для нього «Повторне опитування»

## Як користуватися

Термостат з'явиться зі значеннями температури й уставки. Ставте лише конвертери з довіреного каталогу.
