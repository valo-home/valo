## What it does

Tracks room occupancy from motion and door sensors and creates a Presence device. Adds the trigger "Room became empty".

## One-time setup

1. Assign motion and door sensors to rooms
2. Install and set **Timeout** in minutes (default 10)

## How to use

Use **Room became empty** with a room, for example turn off the lights when the office has been empty for 10 minutes.
