## Что делает

Отправляет сообщения Valo в Telegram. Пересылает уведомления центра (протечка, дым, угарный газ, устройство не отвечает, низкий заряд), дает блок сценария «Сообщение в Telegram» с переменными из события и кнопками действий, отвечает на команды `/status`, `/devices`, `/help`.

## Разовая настройка

1. В Telegram напишите @BotFather, команда `/newbot`, задайте имя. Сохраните токен вида `123456:ABC...`
2. Напишите своему боту `/start`. Для семейного чата добавьте бота в группу и напишите там `/start`. Бот ответит chat id
3. В Valo: Расширения, Каталог, Telegram, Установить. Откройте расширение и вставьте токен
4. Откройте страницу Telegram в меню. В списке «Чаты, писавшие боту» скопируйте строки вида `Семья=-100123` в поле **Получатели**, по одной на строку или через `;`. Имя слева можно поменять, по нему вы будете выбирать получателя в сценариях. Имя вида `@user` не подходит, Telegram не дает боту писать по имени, нужен числовой chat id. Такие строки страница Telegram показывает как непринятые. Ошибка доставки «chat not found» значит, что бота нет в чате или номер чата сменился, например группа стала супергруппой с номером вида `-100...`
5. При желании в поле **Администраторы** укажите Telegram user id людей, которым можно нажимать кнопки и отправлять команды. Пусто значит, что можно всем участникам чатов из списка получателей
6. Сохраните настройки и нажмите «Отправить тест» на странице Telegram

Один бот нельзя подключать к двум средам Valo одновременно (демо и рабочей): Telegram отдает обновления только одному получателю.

## Как пользоваться

**Без сценариев.** Система, Дом, «Уровни уведомлений для внешней доставки»: выберите уровни. Критические уведомления уходят всем получателям со звуком, остальные по выбору.

**В сценариях.** Блок «Сообщение в Telegram»:

- **Получатели**: имена через запятую, пусто значит всем
- **Текст** с переменными: `{device}` устройство, `{room}` помещение, `{cap}` функция, `{value}` значение, `{old}` прежнее значение, `{unit}` единица, `{time}`, `{date}`, `{flow}` сценарий, `{home}` дом, `{low_battery}` устройства с низким зарядом, `{offline}` не на связи, `{alarms}` в тревоге. Неизвестная переменная остается как есть
- **Без звука**: сообщение придет тихо
- **Кнопки**: до двух. Укажите устройство, подпись кнопки и значения, например «Выключить» и Включение нет. Если устройство не выбрано, берется устройство из события. Кнопка действует сутки и срабатывает один раз

Готовые шаблоны в «Сценарии, Новый сценарий»: тревога всем, протечка выбранного датчика, устройство не на связи 30 минут, низкий заряд каждый день, мощность розетки выше порога с кнопкой «Выключить».

**Снимок или клип с камеры.** Блок «Снимок или клип в Telegram» отправляет фото или видео с подписью:

- **Получатели** и **Текст** как у сообщения, в тексте также `{label}` тип события камеры (движение, человек)
- **Камера**: пусто значит камера из события «Событие камеры»
- **Что отправить**: снимок камеры сейчас, снимок или клип из сценария (после действия «Снимок с камеры»), последняя запись камеры или записать клип на заданное число секунд
- **Без звука**: сообщение придет тихо

Файл уходит в фоне, сценарий не ждет отправки. Клип отправляется, когда запись готова, обычно через длительность клипа и еще несколько секунд. Telegram принимает фото до 10 МБ и видео до 50 МБ. Если файл больше или отправка не удалась, приходит текст с причиной и ссылкой на запись. Для ссылки укажите в настройках расширения **Адрес Valo для ссылок**, например `http://192.168.0.10:3100`. Блоку нужны права на чтение и запись медиа, их подтверждают при обновлении расширения.

**Команды бота** (только из чатов-получателей): `/status` сводка дома, тревоги и уведомления, `/devices` устройства по помещениям, `/help`.

**Защита от спама.** Одинаковое сообщение тем же получателям не повторяется чаще, чем раз в N минут (настройка «Повтор не чаще, мин», по умолчанию 10). В тихие часы сообщения приходят без звука, кроме критических.

Ошибки доставки видны в Система, Ошибки и в уведомлениях.
